Ringkasan Studi Kasus

Sistem Kantin Online (BI-KANTIN) dirancang untuk mempermudah transaksi jual-beli di lingkungan sekolah/kampus. Aplikasi ini memiliki 3 aktor utama:

Admin

Mengelola CRUD Menu Makanan/Minuman, Manajemen Akun Pengguna, dan memantau seluruh pesanan masuk.

Siswa (Pembeli)

Melakukan registrasi/login, memilih katalog makanan, membuat pesanan (checkout), dan memantau status pesanan secara real-time.

Kasir / Petugas

Memeriksa daftar pesanan masuk, memvalidasi pembayaran, dan mengubah status pesanan menjadi lunas atau siap diambil.

Activity Diagrams (Alur Kerja)

Berikut adalah rincian diagram aktivitas untuk setiap proses bisnis utama di dalam sistem:

1. Alur Autentikasi (Login & Logout)

Proses masuk pengguna berdasarkan role masing-masing (Admin, Siswa, Kasir).

2. Alur CRUD Menu (Admin)

Aktivitas admin dalam menambah, mengedit, dan menghapus data menu makanan/minuman.

3. Alur Pemesanan (Siswa)

Aktivitas siswa memilih katalog, memasukkan ke keranjang, dan melakukan checkout pesanan.

4. Alur Validasi Pembayaran (Kasir)

Aktivitas kasir memeriksa pesanan masuk dan memvalidasi pembayaran hingga siap diambil.
